# interview-coach

> 来源分类：**待确认** ｜ 导出批次：review

面试准备助手。用户提供简历和岗位JD后，支持两种模式：① 分析考点并生成针对性面试题目和参考答案；②

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/interview-coach        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/interview-coach   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。

- 本技能从本地 WorkBuddy 环境导出，**所有真实密钥已脱敏为占位符**，使用前请配置你自己的 API Key。
